# Imprint project guidelines

Imprint is a hobby-first personal RSVP reader. Read Roadmap.md before expanding scope.

Use Svelte/Vite and the existing Capacitor Android project. Keep the app local-first with IndexedDB and static client assets. Focus on imported books, comfortable reading, chapters and dependable resume. Keep the existing DB name and IDs stable; preserve user books and progress during changes.

Do not reintroduce catalogues, network book search, premium gates, dashboards, ads, goals, cloud services or speculative storage adapters. A possible one-time paid store release follows personal use and device testing. Do not add infrastructure for it prematurely.

Validate parser and persistence changes with meaningful tests. Build the app and document real-device limitations honestly.
